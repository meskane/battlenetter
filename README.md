# battlenetter

Lightweight Battle.net account manager and switcher for Windows.

Early development. Account selection and switching are not implemented yet.

## Roadmap

- Parse and display remembered accounts.
- Add account selection.
- Close Battle.net and safely update the preferred account with a backup.
- Relaunch Battle.net.
- Investigate reliable BattleTag lookup from local data.
